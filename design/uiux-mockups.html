CDIG — three UI/UX directions

All three use the app's real dark theme and layer palette (water #4dabf7, rivers #13c2c2, health #f5222d, schools #52c41a). The goal: make the map the product, add flood-responder essentials (search a place, a real legend, scale/context), and turn the flat toggle+slider list into a scannable control panel. Each option is a genuinely different layout, not a restyle of the same idea.

Option A · “Ops console” — collapsible icon rail + dense layer sidebar + edge-to-edge map (recommended)

Removes the triple-nested title chrome. A 56px icon rail replaces the wide sider; the map goes edge-to-edge with a floating search, zoom, and a real legend. Layer rows are compact (slider appears on hover / when a layer is on), grouped with counts. Reads like a professional GIS/ops tool. Densest information, most map area.

Option B · “Floating glass” — full-bleed map, translucent panels float on top

The map fills the entire viewport; brand, search, layer panel and legend float as frosted-glass cards over it (Mapbox/Google-Maps feel). Layers toggle as chips + a compact list. Map/Downloads become a bottom pill toggle. Most immersive and modern, slightly less dense; panels can overlap the map on small screens.

Option C · “Situation dashboard” — stat header band + grouped sidebar + map

Keeps a top band but makes it earn its space: brand on the left, live at-a-glance stats on the right (layers active, hospitals/shelters in view). Sidebar has search + accordion groups. Best if you later add live data (rainfall, alerts, incident counts); the header gives them a home. Most "command-center", uses a bit more chrome than A.
